开新坑啦。把复习（预习）的一下东西理上来。

:::note[说明：教育文法和学校文法]
本文主要使用教育文法（日本語文法）的术语。为了便于参考，同时也给出学校文法（国文法）的术语。\
教育文法，主要面向非母语学习者，目的是便于理解。《标准日本语》《大家的日本语》等书采用教育文法。\
学校文法，基于古典日语语法，主要面向日语母语者。《新编日语》等日语专业的课本多采用学校文法。
:::

# 动词的分类

## 一类动词（１グループ）

所有辞典形最后一个假名为「う」段除「る」外其他假名的动词，或者为「る」而不属于二类动词、三类动词的动词（见下）属于**一类动词**。

变成ます形时，一类动词的「る」会变成「り」，然后再加上「ます」。

:::note[说明：学校文法]
学校文法中，因为活用时语尾会变化成同一行所有五段（「あ」～「お」段）的假名，所以称其为**五段活用动词（五段动词）**。
:::

## 二类动词（２グループ）

大部分辞典形最后一个假名为「る」，且「る」前为「い」段或「え」段假名的动词属于**二类动词**。

变成ます形时，二类动词的「る」会直接变成「ます」。

【例外】以下动词是**一类动词**：\
<ruby>嘲<rt>あざけ</rt></ruby>る・焦る・<ruby>入<rt>い</rt></ruby>る・<ruby>要<rt>い</rt></ruby>る・<ruby>煎<rt>い</rt></ruby>る・返る・帰る・限る・切る・<ruby>覆<rt>くつがえ</rt></ruby>る・蹴る・<ruby>遮<rt>さえぎ</rt></ruby>る・知る・茂る・喋る・滑る・照る・散る・握る・<ruby>罵<rt>ののし</rt></ruby>る・<ruby>入<rt>はい</rt></ruby>る・走る・減る・参る・混じる・<ruby>漲<rt>みなぎ</rt></ruby>る。

:::note[说明：学校文法]
学校文法中，因为活用时语尾的变化局限于一段的假名，所以称其为**一段活用动词（一段动词）**。其中，「る」前为「い」段假名的称为**上一段活用动词（上一段动词）**，「え」段假名的称为**下一段活用动词（下一段动词）**。
:::

## 三类动词（３グループ）

「来る」「する」以及以「…する」结尾的片假名词、汉字词等（即，动作性名词、副词等后加「…する」构成的复合动词）属于**三类动词**。

:::note[说明：学校文法]
学校文法中，称「来る」为**カ行变格活用动词（カ变动词）**，称「する」以及以「…する」结尾的为**サ行变格活用动词（サ变动词）**。有时，因为其不规则变化，也统称**不规则动词**。
:::

# 动词的变化形式（活用）

以下变化大部分基于**辞书形**（**基本形**）。

## ます形（丁宁形/敬体形）

- **一类动词**：「う」段假名 → 「い」段假名＋「ます」\
    例：話す → 話します　持つ → 持ちます
- **二类动词**：「る」 → 「ます」\
    例：見る → 見ます　食べる → 食べます
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>き</rt></ruby>ます」　「する」 → 「します」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>き</rt></ruby>ます　掃除する → 掃除します

:::note[说明：学校文法]
学校文法中，称**连用形＋「ます」**。
:::

## て形

- **一类动词**：ます形「ます」 → 「て」\
    例：話します → 話して\
    注意音便，规则：
    - （促音便）「い・ち・り」 → 「って」\
    例：会います → 会って　持ちます → 持って　乗ります → 乗って
    - （撥音便）「に・み・び」 → 「んで」\
    例：死にます → 死んで　飲みます → 飲んで　呼びます → 呼んで
    - （い音便）「き・ぎ」 → 「いて・いで」\
    例：書きます → 書いて　泳ぎます → 泳いで
- **二类动词**：ます形「ます」 → 「て」\
    例：見ます → 見て　食べます → 食べて
- **三类动词**：「<ruby>来<rt>き</rt></ruby>ます」 → 「<ruby>来<rt>き</rt></ruby>て」　「します」 → 「して」\
    例：<ruby>来<rt>き</rt></ruby>ます → <ruby>来<rt>き</rt></ruby>て　掃除します → 掃除して

:::note[说明：学校文法]
学校文法中，称**连用形＋「て」**。
:::

## た形

- **一类动词**：ます形「ます」 → 「た」\
    例：話します → 話した\
    ※注：音便规则：
    - （促音便）「い・ち・り」 → 「った」\
    例：会います → 会った　持ちます → 持った　乗ります → 乗った
    - （撥音便）「に・み・び」 → 「んだ」\
    例：死にます → 死んだ　飲みます → 飲んだ　呼びます → 呼んだ
    - （い音便）「き・ぎ」 → 「いた・いだ」\
    例：書きます → 書いた　泳ぎます →だ
- **二类动词**：ます形「ます」 → 「た」\
    例：見ます → 見た　食べます → 食べた
- **三类动词**：「<ruby>来<rt>き</rt></ruby>ます」 → 「<ruby>来<rt>き</rt></ruby>た」　「します」 → 「した」\
    例：<ruby>来<rt>き</rt></ruby>ます → <ruby>来<rt>き</rt></ruby>た　掃除します → 掃除した

:::note[说明：学校文法]
学校文法中，称**连用形＋「た」**。
:::

## ない形（否定形）

- **一类动词**：「う」段假名 → 「あ」段假名（「う」 → 「わ」）＋「ない」\
    例：話す → 話さない　持つ → 持たない　会う → 会わない\
    ※注：ある → ない（い形容詞）
- **二类动词**：「る」 → 「ない」\
    例：見る → 見ない　食べる → 食べない
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>ない」　「する」 → 「しない」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>ない　掃除する → 掃除しない

:::note[说明：学校文法]
学校文法中，称**未然形＋「ない」**。
:::

## 命令形

- **一类动词**：「う」段假名 → 「え」段假名\
    例：話す → 話せ　持つ → 持て
- **二类动词**：「る」 → 「ろ」・「よ」\
    例：見る → 見ろ・見よ　食べる → 食べろ・食べよ\
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>い」　「する」 → 「しろ」・「せよ」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>い　掃除する → 掃除しろ・掃除せよ

:::important[补充：「ろ」・「よ」结尾的两种命令形]
部分动词有两种命令形：「ろ」结尾的为口语；「よ」结尾的为书面语，较为正式。
:::

:::note[说明：学校文法]
学校文法中，称**命令形**。
:::

## 意志形（意向形）

- **一类动词**：「う」段假名 → 「お」段假名＋「う」\
    例：話す → 話そう　持つ → 持とう
- **二类动词**：「る」 → 「よう」\
    例：見る → 見よう　食べる → 食べよう\
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>よう」　「する」 → 「しよう」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>よう　掃除する → 掃除しよう

:::note[说明：学校文法]
学校文法中，称**未然形＋「よう」**。
:::

## ば形（假定形）

- **一类动词**：「う」段假名 → 「え」段假名＋「ば」\
    例：話す → 話せば　持つ → 持てば
- **二类动词**：「る」 → 「れば」\
    例：見る → 見れば　食べる → 食べれば
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>く</rt></ruby>れば」　「する」 → 「すれば」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>く</rt></ruby>れば　掃除する → 掃除すれば

:::note[说明：学校文法]
学校文法中，称**假定形＋「ば」**。
:::

## 可能形（可能形式）

- **一类动词**：「う」段假名 → 「え」段假名＋「る」\
    例：話す → 話せる　持つ → 持てる
- **二类动词**：「る」 → 「られる」\
    例：見る → 見られる　食べる → 食べられる
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>られる」　「する」 → 「できる」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>られる　掃除する → 掃除できる

:::important[补充：无ら形式（ら抜き言葉）]
口语中，有些人会将二类动词、「来る」的可能形里的「ら」省略，称作 **“无ら形式”**（**ら抜き言葉**）。\
例：見れる　食べれる　来れる\
以往「ら抜き言葉」被视为错误，但近年来使用频率有增加的趋势。
:::

:::note[说明：学校文法]
学校文法中，称**未然形＋「れる・られる」**。
:::

## 受身形（被动形式）

- **一类动词**：「う」段假名 → 「あ」段假名（「う」 → 「わ」）＋「れる」\
    例：話す → 話される　持つ → 持たれる
- **二类动词**：「る」 → 「られる」\
    例：見る → 見られる　食べる → 食べられる
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>られる」　「する」 → 「される」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>られる　掃除する → 掃除される

:::important[补充：受身形动词的活用形式]
受身形动词的活用形式**与二类动词相同**。\
例：話される → 話されます　見られる → 見られます　来られる → 来られます
:::

:::note[说明：学校文法]
学校文法中，称**未然形＋「れる・られる」**。
:::

## 使役形（使役形式）

- **一类动词**：「う」段假名 → 「あ」段假名（「う」 → 「わ」）＋「せる」\
    例：話す → 話させる　持つ → 持たせる
- **二类动词**：「る」 → 「させる」\
    例：見る → 見させる　食べる → 食べさせる
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>させる」　「する」 → 「させる」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>させる　掃除する → 掃除させる

:::important[补充：使役形动词的活用形式]
使役形动词的活用形式**与二类动词相同**。\
例：話させる → 話させます　見らせる → 見らせます　来らせる → 来らせます
:::

:::caution[注意：さ入れ言葉]
受到二类动词的影响，有些人会在一类动词的使役形里多加「さ」。这称作さ入れ言葉\
例：（×）~~持た**さ**せる~~　~~行か**さ**せる~~
:::

:::important[补充：使役形的音便]
有时，在非正式的口语中，会把「さ行」＋「て」读成「して」。\
例：行か**せて** → 行か**して**　食べさ**せて** → 食べさ**して**\
使役形的て形之外的例子：いらっ**しゃって** → いら**して**　見**せて** → 見**して**
:::

:::note[说明：学校文法]
学校文法中，称**未然形＋「せる・させる」**。
:::

## 使役受身形（使役被动形式）

- **一类动词**：「う」段假名 → 「あ」段假名（「う」 → 「わ」）＋「せられる」（缩约形「される」）\
    例：話す → 話させられる　持つ → 持たせられる（持たされる）
- **二类动词**：「る」 → 「させられる」\
    例：見る → 見させられる　食べる → 食べさせられる
- **三类动词**：「<ruby>来<rt>く</rt></ruby>る」 → 「<ruby>来<rt>こ</rt></ruby>させられる」　「する」 → 「させられる」\
    例：<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>させられる　掃除する → 掃除させられる

:::important[补充：使役受身形动词的活用形式]
使役受身形动词的活用形式**与二类动词相同**。\
例：話させられる → 話させられます　見させられる → 見させられます　来させられる → 来させられます
:::

:::note[说明：学校文法]
学校文法中，称**未然形＋「せられる」**。
:::
